How winning works

Winning

  1. Play continues until all planning meetings are completed.
  2. If only one player gets Bingo, they win.
  3. If several players get Bingo, the winner has the most Bingos (completed rows, columns, or diagonals).
  4. If still tied, the winner has the most marked squares overall.
  5. If still tied, it goes to an offline tiebreaker.

Marking squares

  • You may only mark a square if you personally witnessed the event happen.
  • You must have been present in the meeting or breakout room when it occurred.
  • If something happened in a different breakout room that you were not in, it does not count for your card.
  • Hearing about an event from another player afterward does not make it eligible to mark.

The live odds and the Players order use these rules: most Bingos first, then most squares marked.
